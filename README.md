# 小红书采集工作台

对标「阿乐采集工作台」的 Chrome 扩展（Manifest V3，侧边栏）。fork 自开源项目 [运营薯 / xhs-chrome-plugin](https://github.com/houht1013/xhs-chrome-plugin)，在其基础上重做为 6 入口采集 + 飞书实时同步 + 本地缓存 + 本地转写（OCR）。

> **自用完整版，不含订单/激活码/发卡平台。** 纯本地运行，不依赖任何第三方签名服务器（见下方「已知限制」）。

## 功能

| 入口 | 说明 |
|---|---|
| 单篇 | 解析当前笔记，封面/标题/昵称/互动数据，一键同步飞书 + 本地转写封面文字 |
| 关键词 | 按关键词采集搜索结果，支持时间/图文视频筛选，实时进度，同步飞书/导出 Excel |
| 联想词 | 批量关键词 → 小红书搜索下拉联想词，本地 5 类意图分类（找服务/问价格/做决策/做对比/问内容），不调 LLM |
| 矩阵 | 多账号 cookie 存档与一键切换（轻量版，不做指纹伪装） |
| 评论 | 当前笔记评论 / 批量链接队列，任务状态可见，可同步飞书 |
| 收藏 | 读取当前收藏列表，手动勾选采集，同步飞书/导出 |

通用能力：
- **飞书多维表格实时同步**：博主 / 笔记 / 评论 / 联想词 / 日常采集库 五张表
- **本地素材缓存**：IndexedDB 双库，原始素材与识别稿分离
- **本地转写（OCR）**：Tesseract.js（WASM）跑在扩展 Offscreen Document，零安装，首次自动下载中文模型
- **Excel 导出**：SheetJS

## 安装（开发者模式）

1. 打开 `chrome://extensions/`
2. 右上角开启「开发者模式」
3. 点「加载已解压的扩展程序」，选择本目录（`xhs-collector`）
4. 打开小红书网页，点工具栏图标打开侧边栏

## 飞书配置

1. 飞书开放平台建**自建应用**，开通「多维表格」权限，拿到 App ID / App Secret
2. 在「凭证与基础信息」生成 **app access token**，换取 **tenant access token**；或直接用开放平台「API 调试」拿到 **Bearer Token**（长期有效的 user_access_token 也可）
3. 复制一份多维表格模板，建 5 张表（博主 / 笔记 / 评论 / 联想词 / 日常），记下每张表的 `table_id`
4. 在扩展「配置」页填入：Bearer Token、多维表格链接（含 `/base/xxx`）、5 张表 ID
5. 顶部出现「飞书已连接」即配置成功

字段约定（写到飞书的值）：
- 笔记表：`笔记ID / 标题 / 链接 / 昵称 / 点赞 / 评论 / 收藏 / 标签 / 识别稿`
- 评论表：`笔记ID / 用户 / 评论 / IP / 回复数`
- 联想词表：`联想词 / 分类 / 来源`

## 本地转写

- 点「配置 → 一键启动并连接（下载识别模型）」首次会从 CDN 下载中文 OCR 模型（约 10MB）
- 之后单篇采集会自动对封面图做本地识别，结果写入缓存与飞书「识别稿」字段
- 模型仅本地运行，不上传任何数据

## 矩阵号

- 「矩阵」页输入账号名 → 「保存当前账号」会存档当前浏览器的小红书 cookie
- 「切换」会清空并注入该账号 cookie，切换后**手动刷新**小红书标签页生效
- 轻量版：仅 cookie 切换，不做浏览器指纹伪装（平台若按设备指纹关联仍可能识别，已知取舍）

## 已知限制 / 风险

1. **XHS 接口无公开 API**：所有接口路径与签名随时可能变；依赖登录态实时请求头，登录失效需重新登录小红书。
2. **签名机制**：默认复用浏览器登录态实时捕获的 `x-s / x-s-common` 头，不依赖第三方签名服务器。如部分接口失败，可在「高级」里填自己的签名服务地址（逃生口）。
3. **Tesseract 中文准确率一般**：二期可换 PaddleOCR / RapidOCR（需本地二进制，更准确）。
4. **频率风控**：批量操作建议把「采集间隔」调大（默认 6 秒）。
5. **仅个人使用**：遵守小红书、飞书服务条款，自行承担使用风险。

## 目录结构

```
xhs-collector/
├── manifest.json          # MV3 + offscreen + 飞书/CDN 权限
├── background.js          # 头捕获 / XHS_FETCH / 飞书同步 / OCR 路由
├── sidepanel.html/js       # 6 tab + 配置 UI 与逻辑
├── styles.css
├── offscreen.html/js       # 本地转写（Tesseract.js）
├── content.js             # 原版 DOM 采集（保留）
├── modules/
│   ├── cache.js           # IndexedDB 缓存
│   ├── feishu.js          # 飞书五表同步
│   ├── exporter.js        # Excel 导出
│   ├── suggest.js         # 联想词 + 分类
│   ├── matrix.js          # 多账号 cookie
│   └── comments-queue.js  # 评论队列
└── README.md
```
